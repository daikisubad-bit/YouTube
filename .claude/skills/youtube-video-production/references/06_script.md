# 5. 台本

企画・差別化ポイント・タイトル/サムネで固めた「何を・なぜ見るべきか」を、実際に視聴者が最後まで見る構成に落とし込む工程。

## 構成の基本

1. **冒頭フック（最初15〜30秒）** — この動画を見るとどんな結果・気づきが得られるかを先出しし、離脱を防ぐ。サムネ・タイトルで
   張った期待（差別化ポイント）を、ここで裏切らずに回収し始める。
2. **本編** — 企画段階で洗い出した論点・エピソードを、視聴者の理解順序に沿って並べる。1トピックが長すぎると離脱の
   原因になるため、要所でパターンを変える（話す→図解→事例、等）。
3. **CTA（行動喚起）** — チャンネル登録・関連動画への誘導・外部導線（LINE等、`00_my_knowhow.md` に指定があればそれに従う）。
   本編の途中に差し込むか、最後にまとめるかは、チャンネルの型に合わせる。

## 台本を書く/直すときのチェック

- サムネ・タイトルで訴求した内容と、台本の主張が一致しているか（否定して良いのは「手法そのもの」ではなく「誤解・間違った
  使い方」であることが多い。断定的に何かを全否定すると信頼を損ないやすい）。
- `00_my_knowhow.md`「5. 台本」の口調・型・NGワードに沿っているか。
- 差別化ポイント（工程4）が、実際に本編のどこかで明確に触れられているか（サムネで釣って中身にないと期待値ズレになる）。

## vidIQツール

- 台本の下書きが欲しいときは `vidiq_generate_script` を出発点として使ってよいが、`00_my_knowhow.md` の口調・構成の型で
  必ず調整する。生成結果をそのまま渡さない。
