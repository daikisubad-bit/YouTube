# 私のノウハウ（チャンネル固有）

このファイルには、daiki本人・このチャンネル固有のノウハウを蓄積していく。ジャンルを問わない汎用の「考え方」は
`knowhow_master.md` にまとまっているので、ここに書くのはそれとは別の、**このチャンネルだから言える具体的な内容**
（ターゲットの解像度、確定文言、過去の実例、NGライン等）。`knowhow_master.md` の 0-2
で言う「別管理」対象（確定版CTA文言、台本指示書、競合リサーチの実データログ、過去台本・壁打ちログ）は、まさにこちらの
役割。

`knowhow_master.md`（汎用の考え方）と内容が重なる場合は、**このファイルの内容が優先**される。

書き方のルール：
- ルールだけでなく、「なぜそうしているか」の理由や、実際にあった成功例・失敗例（数字があればそれも）をセットで書く。
  理由抜きのルールだけだと、想定外のケースに応用できない。
- テキストで箇条書きにして渡してもらえればOK。過去の資料（スプレッドシート、台本、Notion等）をそのまま貼ってもらっても、
  Claudeが該当セクションに整理して追記する。
- 内容は工程ごとにセクション分けしてある。埋まっていないセクションは `<!-- TODO -->` にしてあるので、該当工程の相談が
  発生したタイミングで、ユーザーに1〜2個だけ質問して埋めていく。

## 3. タイトル・サムネ

継続的な壁打ちログは `projects/hikari-thumbnail-audit.md` を参照（画像素材を受け取るたびに随時更新）。以下はそこから
抽出した現時点のベースライン（詳細な実例・倍率は監査ファイル側に記載）。

- **共通フォーマット**：上下2段サンドイッチ構文（上段＝フック、下段＝結論・ベネフィット・CTA）。中央に演者写真＋チャート、
  チャートに黄色◯・矢印で「ここ」を明示。右下に権威タグ固定。書体は白黒縁の極太ゴシック、キーワードのみ黄/赤強調。
  背景は自宅ソファ／ベッドでリラックス（＝簡単・自然体の印象）。
- **効いている型（◎実績あり）**：①絞り込み型／②マネして・丸パクリ型／③Before→After型／④常識否定型／⑤順番・STEP型／
  ⑥実績・数字インパクト型（※規約注意）／⑦異常値・人間ドラマ型／⑧時短・ながら型／⑨警告・逆張り型。
- **伸びにくい傾向**：日次チャレンジ企画の連投（シリーズ疲れ）、抽象的で対比のないベネフィット。
- **競合分析の結論**：専門用語＋一般ベネフィット（「◯◯だけで勝てる」）は競合過多で伸びない。用語を"素材"に降ろし、
  フックを「違い・ココ・正解・常識否定・悩み」に置いたものが化ける。特に比較型（勝てる並び vs 負ける並び）が突出。
  本当に効くのは単純な良い/悪いの対比ではなく「パッと見は同じに見えるのに結果が違う」好奇心ギャップ構造。
