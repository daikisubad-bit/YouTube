# 4. 差別化ポイント

「同じテーマの動画は既にたくさんある中で、なぜこの動画を見るべきか」を1文で言語化する工程。企画（工程2）と同時に検討するのが
実務上は自然だが、抜け漏れやすいので独立したチェックとして扱う。

## チェック項目

1. **競合と比べて何が違うか** — 「情報の新しさ」「演者ならではの実体験・経歴」「独自のデータ・切り口」「見せ方・編集」の
   どれで差別化しているかを明確にする。複数を欲張ると訴求がぼやけるので、主軸は1つに絞る。
2. **「他の人でも言えること」になっていないか** — 専門用語やジャンル共通のベネフィット訴求（「これだけで稼げる」等）は
   競合が飽和しがちで弱い。用語や一般論は"中身"に降ろし、フックは別の軸（違い・具体的な一点・常識否定・悩みの名指し等）に置く。
3. **サムネ・タイトルの主張と矛盾しないか** — 差別化ポイントはこのあとサムネ・タイトルの核になる。動画の中身（肯定するのか
   否定するのか、何を教えるのか）と矛盾しないかを必ず照合する。
4. **`00_my_knowhow.md`「4. 差別化ポイント」の自分の強みと接続しているか** — 差別化は一般論ではなく、自分（演者）の
   経歴・実績・視点に紐づいているほど模倣されにくい。

## 出し方

差別化ポイントは1文で言い切れる形にする（例：「◯◯という点では他のチャンネルは触れていないが、この動画では触れる」）。
言い切れない場合は、企画そのものがまだ抽象的すぎる可能性が高いので、企画ステップに一度戻ることを提案する。
