# 制作運用（全工程を横断する進行管理）

特定の工程ではなく、複数の動画を並行して作るときの進行管理の考え方。詳細は `knowhow_master.md` 第15章。

## 考え方

- **プロデューサーの責任は1本の完成だけではない** — 投稿予定・台本先行・撮影日確定・編集の予備・特典・導線設定が揃い、
  毎日どこで止まっているかが分かる状態を作ることが仕事。
- **最低3本先まで持つ** — 常に「公開直前／編集中／撮影待ち／台本中／企画候補」を並行させる。1本しかパイプラインに
  ないと、どこか一箇所の遅延がそのまま投稿の遅延に直結する。`templates/video_project_template.md`
  を動画ごとに作り、並行して走っているものを一覧できるようにしておく。
- **進捗報告には改善策までセットにする** — 「遅れています」だけで終わらせず、止まっている箇所・誰の回答待ちか・
  期限への影響・代替案までを進行ファイルに書く。
- **依頼は最低限これを明確にする** — 何を作るか／尺／参考動画／目的／必須演出／素材場所／初稿期限／最終期限／修正
  回数／公開日。「早めに」ではなく具体的な日付を出す。

## このツールでの使い方

複数動画を並行管理したいとユーザーから相談されたら、動画ごとの進行ファイル一覧を確認し、どこが詰まっているかを
一緒に洗い出す。詰まっている箇所が特定の工程（例：台本レビュー待ちが3本溜まっている）に偏っている場合は、その工程の
ボトルネックとして扱う。
