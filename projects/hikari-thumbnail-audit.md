# 🎯 ひかりチャンネル｜サムネ・タイトル壁打ちプロジェクト

チャンネル横断のサムネ／タイトル戦略を継続的に詰めるための壁打ちログ。1本の動画の制作進行（`projects/<動画スラッグ>.md`）とは別に、
「ひかりで伸びている要素」と「競合で伸びている要素」の重なりを見つけて、勝てるサムネ文言の型を固めていくためのファイル。

- **開始日**：2026-08-02
- **目的**：現状作成中のサムネを分析 → ひかり過去サムネ＋競合サムネの実データ（再生数・VidiQ数値等）を照合 →
  両者で共通して伸びている「型」を抽出 → サムネ文言をフィックスする
- **進行ステータス**：素材待ち（① 現状サムネ ② ひかり過去サムネ全量 ③ 競合サムネ、を順次受け取り予定）

## 0. 前提：既存の勝ちパターン分析（過去セッションの蓄積を継承）

`yt-growth-coach` スキルの参考データ（`thumbnail_pattern_catalog_example.md`）に、ひかりチャンネルの実データに基づく
勝ちパターン型カタログが既に存在していた。以前の壁打ちセッションで作成されたものと思われるため、今回はこれを
「現時点の仮説・ベースライン」として引き継ぎ、新しく送ってもらう素材で検証・更新していく。

### ひかりの勝ち型（◎=高パフォーマンス実績、過去分析より）
| 型 | 概要 | なぜ効くか |
|---|---|---|
| ①絞り込み型 | 「◯本だけ／これだけ」で手段を極限まで絞る | 簡単・シンプル欲求。線の本数=具体性 |
| ②マネして／丸パクリ型 | 「マネしてみて」「丸パクリして」 | 自分で考えなくていい＝楽・再現性 |
| ③Before→After型 | 「また買ったら下がる…／コレで解決」 | 悩み共感＋解決の対比。初心者に最刺さり |
| ④常識否定型 | 「9割やらない／知らない」 | 希少性＋損失回避＋逆張り |
| ⑤順番／STEP型 | 「この3STEPが結局一番勝てた」 | 初心者は手順に安心する |
| ⑥実績・数字インパクト型 | 「月利2200万円」等（9.3x実績） | 数字でスクロールを止める。※規約注意、断定表現は避ける |
| ⑦異常値・人間ドラマ型 | 「借金280万／どん底シンママ」 | 演者の背景（異常値）でクリック理由を作る |
| ⑧時短・ながら型 | 「朝30分で1万円」 | 楽・スキマ時間欲求（兼業ターゲット） |
| ⑨警告・逆張り型 | 「勉強するな」 | 意外性でクリック |

**伸びにくい傾向**：日次チャレンジ企画の連投（シリーズ疲れ）、ベネフィット/数字が抽象的で対比のないフック。

**共通フォーマット**：上下2段サンドイッチ（上=フック／下=結論・ベネフィット）、チャートに黄色◯・矢印、右下に権威タグ固定
（「小卒FX歴5年目 月利300万トレーダー」等）、白黒縁の極太ゴシック＋キーワードのみ黄/赤強調、自宅リラックス背景。

### 競合分析からの重要な結論（過去分析より・移動平均線キーワードで検証済み）
- ❌ **伸びない**：専門用語が主役＋一般的ベネフィット（「◯◯だけで勝てる」型）。競合過多で飽和。
- ✅ **化ける**：用語は"素材"に降格し、フックを「違い・ココ・正解・常識否定・悩み」に置いたもの。
  特に **①②の比較型（勝てる並び vs 負ける並び）** が突出した倍率（11.9x/3.6x）。
- → **「本当に効くのは"パッと見は同じに見えるのに結果が違う"という好奇心ギャップ」**。単純な良い/悪いの対比だけでは弱い。

この仮説（ひかりの勝ち型 × 競合の勝ち型の重なり）を、今回新しく送ってもらう素材で改めて検証する。

## 2. 分析メモ（画像を受け取り次第、随時追記）

### 2-1. 現状サムネの分析（2026-08-02）

**文言**：「FXは正直、／この順番が一番勝てた」
**構図**：1時間足チャート（ボックスで停滞ゾーン明示）→矢印→15分足チャート（エントリー箇所を丸＋矢印で明示）／ひかりがPCを見る定番カット

**型マッチング**：
- ⑤順番・STEP型（過去実績◎・「この3STEPが結局一番勝てた」2.2x）と③Before→After型（過去実績◎・初心者に最刺さり）の
  ハイブリッド。両方とも既存カタログで実績のある型なので、方向性としては土台が良い。
- ただし「1時間足→15分足」はズームイン型の"解決の可視化"であり、競合分析で最大倍率（11.9x〜22.5x）を出していた
  「パッと見は同じに見えるのに結果が違う」対比・トラップ構造そのものではない。今回は"⑤×③"クラス（実績2.2x水準）に
  収まっている可能性が高く、天井を狙うならもう一段の対比構造化に伸びしろがある。
- 数字断定（「資金20万→300万」系）を意図的に避けた判断は、型⑥の規約リスク＋鮮度低下を踏まえると妥当。

**懸念点**：
1. 画面内の情報量（2チャート＋矢印＋丸＋「1時間足」「15分足」ラベル＋人物）が多く、原則6（文字は短く大きく2ブロックで
   一瞬読み）に対してスマホでの瞬間可読性がやや不安。メインコピー2行の視認性が最優先になっているか要確認。
2. 型の共通フォーマットにある右下権威タグ（「小卒FX歴5年目 月利300万トレーダー」等）の記載がメモになし。ブランド
   一貫性の観点で毎回固定しているなら今回も入れるべきか確認したい。
3. 「敵＝間違った使い方・思い込み」の要素は今回なし（必須ではない）。動画内で「多くの人は15分足だけ見て失敗する」
   等の思い込み訂正を扱っているなら、④常識否定と組み合わせてもう一段フックを強められる可能性。

**次の判断材料待ち**：動画内に「勝てなかった見方 vs 勝てた見方」のような対比要素が実際にあるか次第で、対比・トラップ
構造への強化案を出せるかが変わる。

### 2-3. 分析（重要な発見）

1. **「FXは正直、」プレフィックスは2本とも実績あり、しかも直近の1本は全体最速のVPH（10）で急伸中。**
   今回の現状サムネ案「FXは正直、この順番が一番勝てた」は、この実証済みプレフィックスを踏襲しており方向性は正しい。

2. **「結局一番勝てた」（⑤STEP型）も2.2xで実績あり。** → 現状案はこの2つの実証済み要素を合成した形になっており、
   ユーザーの「過去に反応のあった要素を再構成した」という判断は、実データでも裏付けが取れた。

3. **⚠️重要な訂正：過去のカタログで「◎最強」としていた③Before→After型の代表例「また買ったら下がった…／コレで
   解決しました」は、実データでは8288回視聴・倍率バッジなし＝チャンネル平均並み（外れ値ではない）だった。**
   同型の別例「エントリー後の即逆行／これで解決しました」も1.2x止まり。→ ③Before→After型は「効かない」わけではないが、
   過去のカタログが言うほど"最強"ではなく、**中位の型**として扱いを引き下げる必要がある。単体では強いフックになりに
   くく、①絞り込みや⑤STEPなど別の型と組み合わせて初めて効く可能性が高い。

4. **新しく見えてきた型（今回のデータで確認）**：
   - **⑩「やめたら／変えたら」型**：「これやめたのが月300万のきっかけ」が**全30本中、再生数ダントツ1位（15万回）**。
     「FXでコレやめたら急に稼げた」も同系統。"何かをやめた/変えたことが転機になった"という逆転構造は、
     カタログ未収録だが最重要パターンの可能性が高い。
   - **⑪ゲスト・異次元の他者型**：「月利2200万円／FX歴25年億トレのスキャルピング実演」が倍率2位（11.1x）。
     ひかり自身ではない"異常値の他者"を出すコラボ企画は跳ねやすい。
   - **⑫視聴者証言・社会的証明型**：「負け続きだった視聴者さんが…7日で2.6万円→10万円」（1.3x）。第三者の実例。
   - **②マネして型＋実利特典（早見表配布）の組み合わせは倍率3位（3.7x）**。「マネして」単体（1.1〜1.2x台が中心）
     より、具体的な特典を明示した方が強く跳ねる。LINE導線設計（リードマグネット）とも相性が良い発見。

5. **④常識否定型（「皆やらない」「みんなやらない」系）は同じ言い回しの繰り返しで倍率が逓減**：
   2.2x → 1.1x → 1.2x の順で、同一チャンネル内でもフレーズの使い回しは効果が落ちる（＝シリーズ疲れ・カタログの
   既存知見と整合）。同じ型でも**毎回言い回しを変える必要がある**という実証。

6. **勝率・数字の断定訴求（「勝率80%超えます」）は1.4xと中位止まり。** 規約グレーな割にリターンは大きくない。
   例外は「月利2200万円」（ゲスト・他者の実績として提示）と直近の伸び中2本（「コレを5年続けて20万→月300万」
   「この5つの理由で負け続けました」）――いずれも**新しめ（2週間〜1ヶ月）でまだVPHが高い＝伸び切っていない**ため、
   最終倍率は要追跡。
